# Bruno Ângelo — portfolio

Personal portfolio for Bruno Ângelo (Astro), a backend and full-stack developer
building and operating production web products.

## Stack

- Next.js and React
- TypeScript
- Tailwind CSS
- Curated project case studies

## Development

```bash
npm install
npm run dev
```

Open <http://localhost:3000> to view the site.

## Build

```bash
npm run build
```

The portfolio highlights production systems with real users, including Laravel
and TypeScript platforms deployed with Forge and Coolify and monitored with
Laravel Nightwatch, Grafana, and Prometheus.
